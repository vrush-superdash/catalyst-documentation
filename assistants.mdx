## Open Assistants

1. Log in to Catalyst.
2. Select **Assistants** from the left sidebar.
3. You will see the assistants available in your workspace.

The page displays assistant names and an **Action** column. The action buttons shown beside each assistant allow you to copy or delete an assistant.

## Create an Assistant

1. Open the **Assistants** page.
2. Click **Create Assistant** in the top-right corner.
3. Choose the communication channel you want to use.

The available options shown in the menu are:

- **Voice**
- **SMS**
- **WhatsApp**
- **Messenger**
- **Instagram**
- **Chat Embed**
- **Email**

The form you see next depends on the channel you select.

## Create a Voice Assistant

1. Click **Create Assistant**.
2. Select **Voice**.
3. In the **Assistant Name** field, enter a name for your assistant.
4. In the **Description** field, briefly describe who the assistant is or what it is intended to do.
5. Click **Create**.

### Assistant Name

Choose a name that helps you identify the assistant easily.

Example: `Customer Support Assistant`

### Description

Add a short description of the assistant's purpose.

Example: `This is the main assistant for customer support.`

## What's Next?

Once your assistant has been created, select it from the Assistants page to continue setting it up.
